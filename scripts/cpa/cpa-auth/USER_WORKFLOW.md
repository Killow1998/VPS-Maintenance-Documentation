# 授权交互约定

日常操作由用户直接运行 `python3 cpa-tools/claude_auth.py`。工具承担以下接收、导入、校验和绑定工作，不再需要 GPT 每次启动。操作、续接和故障处理以 [自助运维 SOP](../cpa-tools/README.md) 为准；agent 监督时遵守相同约定。

- 工具或 Agent 启动并保持登录与回调进程，确认监听可连接后提供本次有效授权链接。
- 默认不自动打开 Safari 或其他浏览器；用户在自己选择的隐私窗口打开链接，以隔离账号。
- 用户仅选择账号、完成邮箱验证并确认授权，不承担 token 的复制、传递、制成文件或上传工作。
- 工具或 Agent 自动接收并保存凭据，分别验证真实生成、账号身份和 quota。用户要求 quota 时，三项未全部通过不得报告完成。
- 模型调用默认使用 setup-token；需要补充账号资料授权时说明用途，保留模型凭据并核对同一账号。
- 同账号的额度辅助凭据保持禁用模型调度，绑定到该账号的模型凭据；两份凭据只算一个逻辑账号。身份依据和未知字段必须如实记录。
- 过期链接必须换新并先恢复回调，不能让用户对着已退出的监听进程授权。
