# 免安装 Python 运维终端

核对日期：2026-10-25。可直接使用[单文件脚本](../scripts/vpsctl.py)，不需要 Agent 或 pip。现有部署只接入管理，不重新安装 XBoard。

## 1. 本地启动

需要 Python 3.10+、系统 OpenSSH，以及已经验证主机指纹的 SSH 密钥登录。默认容器 `xboard-xboard-1`、宿主机目录 `/opt/Xboard`、节点服务 `xboard-node.service`，容器内应用在 `/www`。先核对实际部署；不符合时用 `--help` 中的选项覆盖。

克隆或下载仓库后，在仓库目录的本地终端运行：

```powershell
python -B scripts/vpsctl.py --host root@SERVER_IP --port 17724
```

`SERVER_IP` 替换为自己的服务器地址。也可不传 `--host`，启动后填写，或传入已有 SSH 别名。别名的 SSH 端口不是 17724 时需显式指定。脚本拒绝自动接受未知或变化的主机指纹；首次连接先手工核实。

脚本不安装 VPS 工具、不启动新服务、不开放公网管理端口。它在本机空闲端口建立 SSH 隧道，**只监听 `127.0.0.1`**，远端连接 `127.0.0.1:7001`。正常退出会关闭自己启动的隧道。

**终端不再要求输入面板管理员邮箱、密码或用户 ID。** 通过现有 SSH 密钥连接，使用已具备的 Docker/应用管理权限取得专属临时会话，再调用原生管理接口。不会读取或修改管理员密码，也不会从 Markdown 加载凭据。这需要能管理该容器的 SSH 权限，不是给普通订阅用户绕过面板登录。

同一 SSH 连接同时承载本机回环端口转发与临时控制通道；查询、状态和备份不再反复握手。临时 Python 控制进程只随本次连接运行，未在服务器安装文件、服务或定时任务。网页后台仍是已有网站，其登录流程未被修改。

## 2. TUI 操作

默认直接进入全部订阅用户流量表，显示上传、下载、已用、配额和剩余量；管理员/员工不列为可操作的订阅用户。最低尺寸为 64 列、20 行。当前页放不下时自动分页，但一次已经查询全部用户，不需逐个输入 ID。

- 方向键或 `j` / `k` 选择用户，Enter 打开该用户操作，不手填用户 ID。
- `n` / `p` 翻页，`r` 显式刷新，`a` 新增用户，`s` 状态，`t` 总池，`m` 维护，`d` 预演，`q` 退出。按键立即生效，不需再按 Enter。
- 结果页 `n` / `p` 翻页，Enter 返回；用户表格每页重复表头。
- Windows 的订阅结果页可按 `c` 复制完整链接，不会复制显示换行。
- 常规修改选择目标后输入 `y` 确认，其他输入取消。永久删除仍需输入显示的 `DELETE 完整邮箱`，不要求记忆数字 ID。不支持管道自动确认。
- 新增用户的套餐、总池修改的节点直接选择；只有一项时自动选中，不要求查 ID。
- 首次使用可加 `--dry-run` 先查看修改计划。临时授权和 XBoard 原有审计仍会发生，但不提交业务修改、不创建备份。
- 表格带读取时间，翻页和选择只用内存快照；不会因每次按键重查服务器。需要最新用量时按 `r`，业务修改后会重新核对。界面只更新改变的行，避免整屏反复重绘。

| 入口 | 功能 | 范围 |
| --- | --- | --- |
| `s` | 服务、负载、内存、Swap、总池 timer | 本地组件状态，不等于真实转发测试 |
| 首页 / Enter | 全部用户用量 / 所选用户 HTTPS 订阅链接 | 默认列表隐藏 token、UUID、来源 IP |
| `a` | 新增用户 | 使用现有套餐，明确配额与有效天数，生成随机密码 |
| 用户操作 | 修改配额、邮箱、重置、停用、启用、删除 | 不清共享总池；删除还涉及关联订单/统计/工单，优先停用 |
| `t` / `m` | 查询 / 设置节点总池上限 | 保留已有用量，不代替服务商限额 |
| `m` | 重启 panel / node / vps | 分别确认；node 和 vps 会中断代理，先撤销本次会话 |
| `m` | 管理网页 / 套餐 | 复用现有后台，不另建网站 |

管理员和员工账号禁止执行用户修改、重置和删除。终端界面从列表选择目标；命令行可用完整邮箱或唯一用户名，有歧义时不猜测。查询到的数据以面板读取时刻为准，不要求维护本地用户名单。

## 3. 单次命令

全局选项放在子命令前。`USER_NAME` 是用户名/完整邮箱占位符。只有一个套餐或节点时可以省略对应选择参数，存在多个时使用界面选择或显式指定唯一名称。

```powershell
python -B scripts/vpsctl.py --host root@SERVER_IP status
python -B scripts/vpsctl.py --host root@SERVER_IP users
python -B scripts/vpsctl.py --host root@SERVER_IP link USER_NAME
python -B scripts/vpsctl.py --host root@SERVER_IP --dry-run reset USER_NAME
python -B scripts/vpsctl.py --host root@SERVER_IP quota USER_NAME 50GiB
python -B scripts/vpsctl.py --host root@SERVER_IP create friend@example.com --quota 50GiB --days 365
python -B scripts/vpsctl.py --host root@SERVER_IP pool-set 1000GB
python -B scripts/vpsctl.py --host root@SERVER_IP restart panel
```

`GB` 是十进制、`GiB` 是二进制，不接受含义不明的 `50g`。查询可加 `--json` 输出原始字节；`link` 始终只输出指定用户的 HTTPS 链接。单次查询也仅使用 SSH 密钥，不再出现面板密码提示。

`--app-dir` / `--database` 控制宿主机备份路径，`--container` / `--node-service` / `--panel-port` 适配现有部署。**使用写操作前核对数据库路径确实对应运行中容器的数据挂载。**

## 4. 每月重置不是启动脚本

继续使用 XBoard 的用户调度与部署时配置的节点总池任务。脚本不安装额外 cron，不在打开菜单、查询或启动时重置计数。部署时分别核对任务、时区和下一次运行时间，参见[计量与每月重置](04-operations.md#4-计量与每月重置)。本工具不会把缺失的任务静默补成另一份重复任务。

已核对的既有 XBoard 版本对 `expired_at=null` 直接返回空的下次重置时间。因此新增用户要求正的有效天数，选择有效重置方式为“每月一日”的现有套餐，并检查创建后存在 `next_reset_at`。不把“永久有效”当作月度重置保证，不擅自修改其他用户共享的套餐。

用户清零不返还服务商已消耗流量，也不清节点池；服务商账单周期、GB/GiB 和超额费用仍需单独确认。

## 5. 备份、失败和隐私

- 用户和总池业务修改默认先备份宿主机 SQLite，使用在线备份与 `quick_check`。路径为 SSH 账号家目录 `xboard-cli-backups/`，目录 0700，文件受 umask 0077 保护。磁盘不足或备份失败则停止。显式 `--no-backup` 仅跳过本次备份，不跳过确认；其他数据库须另行安排备份。
- 备份包含敏感数据，不发布；脚本不自动删除历史备份，需按自己的保留策略管理。恢复前停止面板写入和后台任务，保留最新状态并审阅差异。不能在线覆盖数据库，整库回退也会回退备份后的其他用户变更和计量。
- 用户操作复用原生管理接口。已核对版本的用户更新接口会清空未随请求带入的邀请关系；工具会保留已核对的邀请关系，无法保留则拒绝修改。
- 节点保存 API 要求完整配置，因此总池修改不回传含私钥的完整节点对象，而通过可信 SSH 在已有 Laravel 中执行带锁、核对旧值的单字段 ORM 事务。只修改 `transfer_enable`，验证其他字段未变，使用现有应用日志记录不含密钥的改动。
- 修改超时不自动重试。新增用户是创建、按需设置个人配额、验收几个步骤，中途失败可能已创建账号，先查询再处理，不重复提交、不自动删除。
- 本工具创建带 15 分钟到期字段、随机专属名称的原生会话，只在内存中持有认证值。正常退出按 ID 和专属名称撤销，不依靠“最新会话”猜测，不删其他设备会话，也不改密码。
- 部分旧版本的 `AuthService::findUserByBearerToken()` 没有校验到期字段，不能仅凭 `expires_at` 声称自动失效。临时控制进程因此另做 15 分钟回收，连接结束/终止信号也尝试按自己登记的随机名称清理；这些逻辑未修改服务器上的 PHP 源码或增加持久任务。主机崩溃、SIGKILL、Docker 不可用等情形仍可能阻止回收，需核查工具命名会话，不能承诺任何异常下都完成删除。
- 密码和订阅链接不会由脚本自动落盘；显式显示、复制后仍需保护终端录屏、剪贴板历史和输出重定向。所有实际服务器、账号和订阅信息都留在仓库外。

2026-10-25 更新：离线业务契约测试通过；Windows 真实 PTY 验证首页全员表、即时方向选择、选中用户后执行模拟操作、预演和退出，不输入账号/密码/ID；实际部署验证了 SSH 授权、全员查询、同连接状态查询、临时会话定时回收和正常撤销。未为测试修改生产用户、清零计量或重启服务。

```powershell
python -B -m unittest discover -s scripts -p test_vpsctl.py -v
```

这些验证不代表任意后续 XBoard 版本兼容。接口、验证规则或响应结构不匹配时停止，不自动安装、迁移或升级。首次使用写操作，应先预演，并在自己的测试账号上验收，不以真实用户做删除测试。
